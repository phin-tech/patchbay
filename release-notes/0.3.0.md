## Teams

- **Subscribe to a team's git repository.** Servers ▸ Subscribe to a Team… takes a git URL or `owner/repo` on GitHub and
  lists everything it adds before you keep it. Patchbay checks each team every hour, shows its changes above your
  servers, and takes in exactly the commit you reviewed when you choose Accept.
- **Private repositories on GitHub** work once you've signed in with the GitHub CLI (`gh auth login`), for teams and
  skills alike.
- **Settings ▸ Teams** lists the teams you're subscribed to, checks them now, and turns the hourly check off.

## Getting started

- **Welcome** opens at a first launch: what Patchbay is, importing or adding your servers, the tools it found, the keys
  worth knowing first, and the menu bar. It's in the Help menu and Settings after.
- **Take the Tour**, from Welcome, Help or Settings, walks through the window on your own servers, changing nothing.

## Menus and the palette

- Every button beside a server is in the Servers menu now, and so in the palette (⌘K): Edit Server, Turn Server On and
  Off, Restart, Sign In and Out, Change Server's Key and Remove Server.
- Take Over the Client's Servers moved to the Clients menu.

## Settings

- **The menu bar shortcut** (⌃⌥⌘Space) can be changed in Settings ▸ General, and works at once.
